# Amazon 美国站核心市场数据获取决策表与准入阻塞报告 (MARKET-DATA-FIRST)

> **核心原则**：
> 1. **先证明数据能拿到，再写适配器**：不先写数千行采集代码再去发现来源不允许使用；
> 2. **不能拿外围数据冒充核心数据**：CPSC 召回不等于销量，Google 趋势不等于 Amazon 站内搜索量，目录不等于畅销榜；
> 3. **区分事实与推论**：当前没凭据 ≠ 接口不存在；接口存在 ≠ 允许用于竞争市场情报；免费试用 ≠ 长期免费；一次请求成功 ≠ 允许持续保存历史；
> 4. **停止无关建设**：在所有核心来源因资格、许可或费用受阻时，坚决停止开发依赖空数据的空功能。

## 二、2026 年最新官方文档与行业规范核查事实

### 1. SP-API 个人卖家开发者准入门槛（2026 官方条文）
- **官方规定**：根据 Amazon Seller Central 开发者中心最新政策，**Individual Selling Plan（个人卖家计划）无法注册或使用 Selling Partner API (SP-API)**；
- **必要条件**：
  1. 必须升级为 **Professional Selling Plan（专业卖家计划，每月固定月租 $39.99）**；
  2. 必须具备企业或已核验的卖家实体；
  3. 必须通过 Amazon Developer Profile 安全审查，并同意《Data Protection Policy (DPP)》与《Acceptable Use Policy (AUP)》；
  4. 访问 **Brand Analytics (ABA 搜索热词)** 还需通过 **Amazon Brand Registry（必须持有美国或合规国家真实注册商标）** 并分配品牌代表角色。
- **结论**：在用户当前个人身份、无卖家账号、零额外预算（¥0）约束下，SP-API 属于**绝对的资质门禁 (`ACCOUNT_GATED`)**，并非系统未写代码，而是官方准入资质无法满足。

### 2. PA-API 5.0（联盟商品接口）协议禁令与考核（2026 官方条文）
- **准入考核**：申请 Amazon Associates 后，必须在 **180 天内产生至少 3 笔合格引流销售**，且需持续出单维持 API 激活；
- **用途明文限制**：
  - **24 小时缓存上限**：协议严格规定非图片内容最长仅允许本地缓存 24 小时，必须重新拉取刷新；
  - **禁止用于市场情报与历史分析**：PA-API 授权范围严格限定为向 Amazon 导流（Drive Traffic）；协议**明文禁止将 PA-API 数据用于构建内部商业情报库（Market Intelligence）、竞品追踪数据库（Competitor Tracking）或历史价格走势（Price History Database）**；
- **结论**：即使完成 3 笔出单考核，PA-API 在法律上**禁止**用于支持 LightChoice Radar 的跨周期积累与选品分析，属于 `NOT_SUITABLE`。

### 3. Keepa 与商业 API 的真实费用
- **官方事实**：Keepa API 独立于 Keepa 网页版插件，**完全没有免费版本 (No Free Tier)**；
- **最低门槛**：最基础套餐价格为 **€49/月（约合人民币 380 元/月）**，按 20 tokens/分钟生成速度计费；
- **结论**：属于 `PAID_REQUIRED`，直接违背 ¥0 预算原则。

### 4. SP-API 官方商品与排名能力实证（Catalog Items v2022-04-01）
- **官方参数核验**：通过查询官方开发者文档，`includedData` 枚举中明确支持：
  `attributes`, `classifications`, `dimensions`, `identifiers`, `images`, `productTypes`, `relationships`, `salesRanks`, `summaries`；
- **BSR 字段证实**：指定 `salesRanks` 参数时，官方返回商品在各分类节点下的实时排名数字与链接（例如 `"rank": 42, "title": "QLED TVs"`）；
- **结论**：**官方确实存在查询商品属性与排名的成熟接口**，系统当前已建立对应标准字段模型，一旦用户未来配置专业卖家凭据，即可无缝激活。

## 三、用户最关心的五个核心问题答复

### 问题一：目前到底能自动获得什么 Amazon 数据？
1. **强制合规与产品避坑反证（已全面自动打通）**：
   - 来源：美国消费品安全委员会（CPSC）官方通告流；
   - 字段：涉及品类、召回原因、产品缺陷、官方发布日期；
   - 定位：用于产品开发安全防呆、材料阻燃避坑与差异化反证；**严禁误报为商业商机**。
2. **全网宏观搜索趋势（可通过公共接口获取）**：
   - 来源：Google Trends 公共数据；
   - 字段：宏观关键词周度相对热度趋势（0~100）；
   - 定位：用于判断大盘需求周期；**不能代表 Amazon 站内实际搜索量与转化**。
3. **Amazon 站内核心商业数据（搜索量、真实排名、竞品报价、新品变化）**：
   - **目前无法合法、免费、全自动获取**。

### 问题二：这轮有没有取得真正的 Amazon 数据？
- **没有取得新的真实 Amazon 站内实时商业数据**。
- 本轮对官方 SP-API、PA-API 5.0、Keepa、开放条形码库、BSR 网页等全部潜在通道进行了 2026 最新官方条文和实测核实，确认在**零额外费用（¥0）、无专业卖家账号、不使用违规黑产爬虫**的前提下，不存在合法、免费、可自动化沉淀历史的 Amazon 站内核心数据通道。
- 系统**坚决不拿合成数据充当真实数据，坚决不拿 CPSC 召回数据充当选品商机**。

### 问题三：如果没有，真正卡在哪里？
真正卡在以下三个客观壁垒，**绝非系统尚未开发代码，而是底层准入与规则硬约束**：
1. **账号资质门禁（硬约束）**：
   Amazon 官方 SP-API 涵盖最完整的商品属性、销售排名（`salesRanks`）和 Brand Analytics 搜索词频率报告（ABA），但**官方明文要求必须为专业卖家（$39.99/月），个人卖家（Individual）无开发者资格**；Brand Analytics 还需要持有官方注册商标并通过 Brand Registry 品牌备案。当前用户未配置此类账号。
2. **零费用硬约束（硬约束）**：
   第三方数据服务（如 Keepa API 最低 €49/月，Rainforest 试用 100 次后断供）均需按月付费订阅，直接违背项目 ¥0 预算红线。
3. **平台协议与合规红线（合规约束）**：
   - PA-API 5.0 协议明文禁止将数据用于非导流用途的市场情报与价格历史库；
   - Amazon 网页公开抓取受 `robots.txt` Disallow 明确禁止，且受 BTS 防火墙严格拦截，无住宅代理池必遭 503 封禁，违背合规底线。

### 问题四：这轮真正改进了什么？
1. **第一性原理事实纠偏**：彻底终结了“到底是接口不存在还是我们没写好代码”的含糊状态，查清并引用了 2026 年 Amazon 官方开发者政策条文，锁定了每一类数据的真实瓶颈；
2. **建立全景决策表**：形成了包含 10 大候选来源、18 个评估维度的决策矩阵，明确标注了 `ACCOUNT_GATED`、`NOT_SUITABLE` 与 `PAID_REQUIRED`；
3. **停止无效与欺诈性建设**：坚决停止在没有数据源的前提下继续开发空适配器、空页面、模拟商机和虚假排名预测；
4. **守住系统诚实底线**：保持 Web 看板的真实空态，杜绝把 Worker 运行伪装成 Amazon 数据实时监控，杜绝把安全反证伪装成暴利热卖品。

### 问题五：用户下一步到底需要做什么？
根据当前客观事实，为用户提供以下三个明确、现实的选择：

* **选择一：保持现状（¥0 零费用，完全合规，当前推荐）**
  - **花费**：¥0；
  - **操作**：用户无需任何操作；
  - **现状**：系统保留现有全自动架构、本地调度、CPSC 安全反证及前三主线成熟能力，第四主线商业板块保持诚实空态；
  - **价值**：不产生任何封禁风险与额外账单，不维护容易崩溃的黑产爬虫。
* **选择二：注册官方 Amazon 专业卖家账户（官方正规商业路线）**
  - **花费**：固定月租 $39.99/月（约合人民币 285 元/月）；
  - **操作**：在 Amazon 卖家中心注册专业卖家计划，开通 SP-API 开发者权限；若有注册商标，一并开通 Brand Registry；
  - **获得**：官方全美 ASIN 商品目录（Catalog Items）、官方分类 BSR 排名（`salesRanks`）、竞品报价（Pricing）及品牌搜索热词报告（Brand Analytics）；
  - **接入方式**：系统已完成所有模型与接入点准备，只需在 `.env` 中填入 Client ID、Secret 与 Refresh Token，即可全自动解锁。
* **选择三：订阅第三方商业数据 API（如 Keepa API）**
  - **花费**：最低 €49/月（约合人民币 380 元/月）；
  - **操作**：在 Keepa 开发者平台注册并订阅 API Token 计划，获取 API Key；
  - **获得**：全美 ASIN 历史价格波动、BSR 走势、Buy Box 卖家变动；
  - **接入方式**：在系统预留的第三方扩展接口中填入 Key 即可实现周期轮询。
